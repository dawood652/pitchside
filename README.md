# Pitchside

A broadcast-style 11-a-side football game in the browser (three.js + TypeScript). All clubs, players and brands are fictional.

**Play:** https://dawood652.github.io/pitchside/

On iPhone: open the link in Safari → Share → **Add to Home Screen**, then launch it from the icon for full-screen play without the browser bars.

## Develop
```
npm install
npm run dev      # local dev server
npm test         # vitest
npm run build    # single-file build in dist/
```
The playable site is served from `docs/` (a copy of `dist/`).

Player models and animations: Quaternius Universal Animation Library (CC0).
